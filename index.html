maraOS — Welcome

Welcome to maraOS

Built with Alegreya & C. Rendered on a raw framebuffer. Zero dependencies.

🎨

Alegreya UI

Serif typography, macOS-style traffic lights, gradient desktop — all drawn pixel-by-pixel.

🔊

Boot Chime

A three-note C-E-G arpeggio plays through the PC speaker on startup. Pure PIT programming.

⚡

Bare Metal

Compiled with -ffreestanding. No stdlib, no runtime, no OS above the kernel.

📦

One File

The entire kernel is a single kernel.c. Framebuffer, GUI, font, sound — all inline.

🚀

Limine Bootloader

BIOS + UEFI bootable ISO via xorriso. Boots on real hardware and QEMU alike.

🖥️

macOS Aesthetic

Blurred dock, rounded windows, vibrant gradient — the look, distilled to its essence.

Build & Run

Four files you write. Two things you download. One command to boot.

# 1. Make the project folder
mkdir maraOS && cd maraOS

# 2. Create these four files with your text editor:
#    → Makefile
#    → limine.cfg
#    → linker.lds
#    → kernel.c

# 3. Download the Limine header
curl -L -o limine.h https://raw.githubusercontent.com/limine-bootloader/limine/v8.x/limine.h

# 4. Clone the bootloader folder
git clone https://github.com/limine-bootloader/limine.git \
     --branch=v8.x-binary --depth=1 limine

# 5. Build & boot
make run
